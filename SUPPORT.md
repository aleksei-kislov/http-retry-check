# Support

Support is provided on a community best-effort basis, with no guaranteed
response time.

Read the [quick start](docs/guides/developer-quickstart.md) and search existing
issues first. Then use the **Usage question** issue form for help or the
**Bug report** form for a reproducible defect.

Include the language, source version, toolchain, command, output, and a small
reproduction. Remove credentials and private data first.

## Security

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).
