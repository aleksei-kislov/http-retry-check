# Contributing to HTTP Retry Check

## Before you start

Search existing issues and pull requests. Open an issue before making a
substantial behaviour, API, schema, dependency, or scope change.

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md).

For code changes, follow the
[source-development guide](docs/guides/source-development.md) and include
relevant tests.

## Open a pull request

Use the pull request template. Explain what changed and how you tested it.
